# AI Usage Info

## Sinn der Library

`phore/schema` erzeugt abstrakte Schema-Modelle aus PHP-Klassen. Der Einstiegspunkt ist `Phore\Schema\Parser\SchemaParser`. Aktuell werden Klassen per Reflection analysiert und öffentliche Properties als `ClassSchema`/`PropertySchema` mit nativen PHP-Typen, PHPDoc-`@var`-Typen, Beschreibungen, Tags, Nullbarkeit, Default-Werten und Array-Art (`list`, `map`, `array`) abgebildet.

Parser-Klassen liegen unter `Phore\Schema\Parser`. Die Schema-Modelle inklusive `DocBlock`, `FunctionSchema`, `FunctionParameterSchema` und `FunctionReturnSchema` liegen unter `Phore\Schema\Schema`; unterstützte abstrakte Typen liegen unter `Phore\Schema\Schema\Type`:

- `PrimitiveSchemaType` für skalare Typen, `null` und `mixed`
- `ClassReferenceSchemaType` für Objekt-/Klassenreferenzen
- `ArraySchemaType` für Arrays inkl. PHPDoc-Generics wie `T[]`/`list<T>` (`arrayKind=list`) und `array<string, T>` (`arrayKind=map`)
- `UnionSchemaType` für nullable/union types
- `IntersectionSchemaType` für Reflection-Intersection-Types

JSON-Generatoren liegen unter `Phore\Schema\Generator\JsonSchema`. `JsonClassSchemaGenerator::generate(SchemaType $schemaType, ?JsonSchemaGeneratorOptions $options = null)` erzeugt ein `JsonSchema`-Wrapper-Objekt. `JsonSchema::data()` liefert das Schema als Array, `toArray()` ist ein Alias, `toString()` serialisiert es als JSON. Über `JsonSchemaCompatibility` (`JsonSchema202012`, `OpenAiStructuredOutput`, `Minimal`) werden unterstützte Keywords gesteuert. Verschachtelte `ClassSchema`-Typen werden je nach Options inline gemerged oder als `$defs`/`$ref` ausgegeben.

Validierung liegt unter `Phore\Schema\Validator`. `Validator::validate(SchemaType $schemaType, mixed $data): bool` prüft Array- oder Objektstrukturen gegen SchemaTypes; Fehler können über `getErrors()` gelesen oder mit `assertValid()` als Exception geworfen werden.

Typische Nutzung:

```php
$schemaParser = new \Phore\Schema\Parser\SchemaParser();
$schema = $schemaParser->parseClass(MyDto::class);
$functionSchema = $schemaParser->parseFunction('my_function');
$methodSchema = $schemaParser->parseMethod(MyService::class, 'handle');
$array = $schema->toArray();
$jsonSchema = $schema->toJsonSchema();
$jsonSchemaArray = $jsonSchema->data();
$jsonSchemaString = $jsonSchema->toString();
// oder direkt mit Compatibility-Options:
$jsonSchema = (new \Phore\Schema\Generator\JsonSchema\JsonClassSchemaGenerator())->generate(
    $schema,
    new \Phore\Schema\Generator\JsonSchema\JsonSchemaGeneratorOptions(
        compatibility: \Phore\Schema\Generator\JsonSchema\JsonSchemaCompatibility::OpenAiStructuredOutput,
    ),
);
$isValid = (new \Phore\Schema\Validator\Validator())->validate($schema, ['name' => 'Jane']);
```

## Globale Funktionen

```php
$classSchema = phore_schema_class(MyDto::class)->toJsonSchema()->data();
```

- `phore_schema_class(string|object $classNameOrObject): \Phore\Schema\Schema\ClassSchema` erstellt ein Klassen-Schema über `SchemaParser::parseClass()`.
